# ExCut

A Python GUI application to cut and collect exercises from photos or PDFs and export them into a single PDF document.

## Features
- Load multiple images or PDFs via CLI.
- Navigate through pages.
- Select and cut areas (Rectangular selection).
- Combine multiple cuts into one exercise.
- Export collected exercises to a PDF.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python3 src/main.py input1.pdf input2.jpg
```
